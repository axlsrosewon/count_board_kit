# Count Board Kit

Local-first Flutter Android app for creating multiple tally counters for
inventory checks, events, attendance, habits, packing batches, and similar
counting work.

## Release

- Package: `com.nst.countboardkit`
- Version: `1.0.0+1`
- Privacy policy: `https://axlsrosewon.github.io/count-board-kit-privacy/`
- Contact website: `http://nst21c.com`
- AAB: `build/app/outputs/bundle/release/app-release.aab`
